## 🎯 Desafio: Extraindo Insights do Feedback de Clientes Bancários

Construção de um prompt estruturado para IA capaz de extrair insights acionáveis de feedbacks bancários, com classificação por tema, sentimento e urgência — respeitando LGPD e dados sensíveis.

## 🚀 Como usar o prompt

1. Copie o prompt de [`desafio-insights-feedback-bancario.md`](./desafio-insights-feedback-bancario.md)
2. Cole em uma IA (ChatGPT, Gemini, Copilot)
3. Substitua `[INSIRA AQUI OS COMENTÁRIOS]` pela sua base de feedbacks
4. Receba resumo executivo, tabela de insights e prioridades
